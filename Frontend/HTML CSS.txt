Types of Boxes:
Inline Boxes - The elements which occupies exact width needed for the content. Height and widths do not apply. Padding and margins are applied only horizontally(left and right). Eg) strong, a , button , em, pseudo-elements after and before,  etc
Block Level Boxes(Elements) - The elements which occupies all spaces they can and have a line break. They cannot be places side by side. Eg) body, main, header, footer, section, nav, aside, div, p, h1-h6, ul, ol, li, etc
Inline-Block - Originally Inline but can apply block properties

Positioning
Normal Flow : Default Positioning(position:relative): Element is "in flow"
Absoulute Positioning : position:absolute : Element is removed from the normal flow "out of flow".
