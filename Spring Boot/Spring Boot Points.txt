@ConditionalOnClass vs  @ConditionalOnMissingBean:
==================================================

@ConditionalOnClass
-------------------
Is a particular class present on the classpath? Enables configuration only if a dependency (JAR/class) exists


@ConditionalOnMissingBean
--------------------------
Has the user already defined this bean? Ensures user-defined beans override auto-config

@AllArgsConstructor vs  @RequiredArgsConstructor
================================================
@AllArgsConstructor
--------------------
Generates a constructor with one parameter for every field in the class.
1) Includes all fields
2) Includes final fields
3) Includes non-final fields
4) Includes fields with default values

@RequiredArgsConstructor:
-------------------------
1) Include final fields
2) Fields annotated with @NonNull
